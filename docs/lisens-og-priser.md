# Lisens og priser

| Lisensmodell         | Pris                      |
| -------------------- | ------------------------- |
| Per elev per år      | 29 kr eks. mva.           |

- Lisensen kjøpes av skoleeier for én eller flere skoler, og gjelder for elevene på 1.–4. trinn ved skolen.
- Lærere har gratis tilgang ved skoler med lisens.
- Bokmål og nynorsk koster det samme og leveres samtidig.
- Prøvelisens: 30 dager gratis for én klasse.
- Abonnementet løper per skoleår (1. august–31. juli) og kan sies opp med tre måneders varsel.

Eksempel: en skole med 100 elever på 1.–4. trinn betaler 2 900 kr per år.
