# Fag, trinn og kompetansemål

Fossilfinneren er laget for naturfag på barnetrinnet, 1.–4. trinn, etter læreplanen i naturfag (NAT01-04, LK20).

## Fagkoder og trinn

| Fagkode | Fag og trinn         | Trinnkode  |
| ------- | -------------------- | ---------- |
| NAT0001 | Naturfag 1. årstrinn | aarstrinn1 |
| NAT0002 | Naturfag 2. årstrinn | aarstrinn2 |
| NAT0003 | Naturfag 3. årstrinn | aarstrinn3 |
| NAT0004 | Naturfag 4. årstrinn | aarstrinn4 |

## Tema

fossiler, dinosaurer, arter som dør ut

## Kompetansemål

Etter 2. årstrinn (KV1075):

- utforske et naturområde i nærmiljøet og beskrive hvordan noen organismer er tilpasset området og hverandre (KM13810)
- oppleve naturen til ulike årstider, reflektere over hvordan naturen er i endring, og hvorfor året deles inn på ulike måter i norsk og samisk tradisjon (KM13811)

Etter 4. årstrinn (KV1076):

- utforske og sammenligne ulike dyre- og plantearters tilpasninger til miljø og levesteder og drøfte hvorfor noen arter dør ut (KM13825)

## Tverrfaglige temaer

- Bærekraftig utvikling – hvorfor arter dør ut, og hva som skjer når miljøet endrer seg.

Oppdragene i tjenesten er merket med kompetansemålet de dekker, se [apps/web/src/curriculum.ts](../apps/web/src/curriculum.ts).
